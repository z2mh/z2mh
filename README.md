# Abdulrahman Alzahrani

Computer Science student at the **University of Manchester**, working across software engineering, computer graphics and systems programming.

My university work ranges from interactive 3D scenes and team web applications to processor emulation, cache policies and digital logic.

| [EventLite](PROJECTS.md#eventlite) | Team event-management application with web and REST interfaces | Java, Spring Boot, JPA, H2 |
